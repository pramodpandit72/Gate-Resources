# GATE Resources

Structured study material and exam resources for **GATE Computer Science and Information Technology (CS/IT)** preparation.

This repository brings together topic-wise notes, official syllabus references, and previous-year question papers in one place. It is designed for learners who want to build concepts from the fundamentals and then practise at GATE level.

## What is included

- Detailed Markdown notes for core GATE CSE subjects
- Engineering Mathematics notes covering discrete mathematics, calculus, linear algebra, and probability and statistics
- GATE 2027 Computer Science and General Aptitude syllabus PDFs
- GATE CS previous-year question papers and available answer keys
- Practice questions, revision material, algorithms, pseudocode, formulas, and worked examples

The notes generally follow this learning pattern:

1. Learn the definitions and prerequisites.
2. Understand the underlying reasoning and formulas.
3. Trace examples and algorithms by hand.
4. Attempt practice questions without looking at the solutions.
5. Use the revision sections to consolidate important ideas.

## How to use this repository

1. Start with the relevant syllabus and identify the topics you need to cover.
2. Read the corresponding notes in `Notes.md/`.
3. Maintain your own error log while solving the practice questions and PYQs.
4. Revisit the revision sections regularly.
5. Cross-check important facts, dates, and official updates with the official GATE website.
